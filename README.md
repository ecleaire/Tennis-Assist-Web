# RoboSports Assist

![TypeScript](https://img.shields.io/badge/TypeScript-Vite-3178C6?logo=typescript&logoColor=white)
![Web](https://img.shields.io/badge/Platform-Web-2ea44f)
![PWA](https://img.shields.io/badge/PWA-Supported-8A2BE2)
![Offline](https://img.shields.io/badge/Offline-Supported-orange)

WRO RoboSports Double Tennis の試合準備、タイマー進行、ボール配置、試合記録、対戦履歴確認を支援する軽量 Web アプリです。

Godot Web 版から HTML / CSS / TypeScript ベースへ移植し、iPad、タブレット、スマートフォン、PC で素早く開けることを重視しています。大会運営、練習、試合記録の補助ツールとして利用できます。

## バージョンの違い

### RoboSports Assist

大会当日の審判・運営で使うことを想定した版です。

- ホーム画面は「試合開始」から始まる大会運営フロー
- チーム選択、コート選択、ボール配置抽選、試合時間抽選、タイマー、リザルト入力、最終確認、代表同意、結果確定までを順番に進行
- 試合中は不要なモード移動を抑制し、記録と送信の流れを優先
- ニュース画面は非表示
- タイトル表示は `RoboSports Assist`

### RoboSports Assist general

練習、確認、選手利用、通常の補助用途を想定した汎用版です。

- ホーム画面にタイマーとボール配置を表示
- タイマー、審判タイマー、ボール配置、試合記録、ルール、ニュース、リンクを個別に利用可能
- 大会用と同じ試合運営フローを「試合運営」モードとして利用可能
- ニュース画面を表示
- タイトル表示は `RoboSports Assist general`

## 主な機能

### タイマー

- 1:00 から 2:00 の試合時間をランダム生成
- 抽選間隔を 1秒 / 5秒 / 10秒単位で切り替え
- 開始、一時停止、再開、終了、リセットに対応
- タイマー開始時の全画面表示に対応
- スマートフォン、タブレット、PC の画面サイズに応じて数字サイズを自動調整

### 10カウント / 5カウント

- 10カウントは「コールドカウント」として表示
- 5カウントは「オーバーボール」として表示
- メインタイマーと同時に表示しても大きくレイアウトが崩れないよう調整
- 全画面表示でも視認しやすいサイズに最適化

### ボールランダマイザー

- WRO RoboSports Double Tennis のボール配置をランダム生成
- フィールド画像上にオレンジボール、紫ボールを表示
- 初期位置へ戻す機能
- 全画面表示に対応
- スマホ縦画面ではホーム画面で上にボール配置、下にタイマーを表示

### 試合記録

- チーム A / チーム B、コート、マッチ結果を記録
- 第1から第3マッチまでの結果を管理
- オレンジボール、紫ボールの数を入力
- ボール数の保存前チェック
- マッチ保存前の確認フロー
- 代表同意、試合結果確定、試合終了表示に対応
- 保存済み、未送信、送信済みの状態表示

### 対戦履歴 / 統計

- 端末内に対戦履歴を保存
- 最新履歴を一覧表示
- チーム別の履歴、勝敗、取得率、紫取得率を確認
- CSV インポート / エクスポートに対応
- スプレッドシートからの一時読み込みに対応
- 同じ履歴の重複読み込みを抑制
- 未送信、送信失敗の履歴を強調表示し、一斉再送信に対応

### GAS / スプレッドシート連携

- Google Apps Script Web アプリ URL を設定して試合結果を送信
- 送信テスト、試合結果、マッチ結果、対戦履歴を用途別シートへ送信
- 送信できなかった履歴は端末に保持し、オンライン復帰後の再送に対応
- 未送信や送信失敗は、API キー未入力、GAS 未接続、ネットワーク、API キー不一致などの原因を表示
- GAS 接続時にスプレッドシートの「チームリスト」シートからチーム情報を読み込み可能
- 同時書き込み対策として GAS 側で LockService を使用

### バックアップ運用

- 試合結果は端末内履歴にも保存され、GAS 送信に失敗しても後から再送できます。
- `archive` 系シートには送信原本を残し、`試合結果` シートは運営表に必要な最小構成で扱います。
- `試合結果` シートは手動修正を想定し、既存行を GAS が勝手に上書きしない方針です。
- 大会当日は、管理画面の「接続・設定読込」、ホームの端末・接続情報、対戦履歴の未送信件数を確認してください。

### QR / URL 読み込み

- GAS URL、スプレッドシート URL、チームリスト URL の入力に対応
- QR コード読み込みに対応
- URL 手入力からの読み込みに対応
- 読み込み済みチームリストを端末へ保存可能

### ルールモード

- WRO 2026 Japan RoboSports Double Tennis ルールの簡易確認用表示
- 検索、項目別表示に対応
- スマホではルール項目をメニュー形式で表示
- 正式な内容を確認するための公式ルールリンクを用意

### ニュース

- 公式 Q&A 更新やアプリ機能更新などの情報を表示
- カテゴリ別に確認可能
- general 版で利用可能

### リンクモード

- WRO 全国 / 国際ホームページ
- WRO 公認予選会ホームページ
- ルール関連リンク
- YouTube 関連動画
- スマホでも見やすいようカテゴリ単位で整理

### PWA / オフライン対応

- ホーム画面へ追加してアプリのように起動可能
- Service Worker により基本アセットをキャッシュ
- オフラインでも UI、タイマー、ボールランダマイザー、試合記録、ローカル履歴確認を利用可能
- GAS 送信、スプレッドシート読み込み、外部 URL へのアクセスはオンライン接続が必要

## 大会編成・進行管理アプリ

`mie-tournament-app` は地域固定ではなく、全管理者共通の大会編成アプリです。

- メインアプリと同じ管理者パスワードでログイン
- ログイン後は30分更新式の短期セッショントークンを使用し、各APIへ管理者パスワードを再送しない
- master スプレッドシートの「GAS管理」から、対応する Web アプリ URL とスプレッドシートを自動解決
- チームリストの「グループ」列（例: `4チーム,4グループ`）を読み込み、グループごとに異なるチーム数も編集・保存
- グループ総当たりをタイムスケジュールの初期値として生成し、調整時間・休憩も追加可能
- 総当たりはグループを交互に配置し、同一チームの連戦を避けながら同じグループは同じコートを優先
- チームリストのコート数を初期値として読み込み、システム側の手動設定は以後優先して保存
- コートはA〜Z表記（5コートならA〜E）で自動割当し、候補選択と手入力の両方に対応
- トーナメント参加枠数を手動設定し、左→右／下→上の勝ち上がりと横書き／縦書きを切り替え
- 下→上表示は「縦長チーム枠＋コート・時間」と「対戦チーム詳細表示」を切り替え可能
- 下→上表示の参加枠・試合枠・優勝枠の幅と高さ、ラウンド間隔、背景色を詳細設定からアカウント別に保存
- トーナメント参加チームを枠ごとに手動選択し、人数・対戦表・タイムスケジュールへ即時反映
- 参加チーム指定と表示詳細設定は通常時に折りたたみ、試合ID・文字サイズ・文字位置などを必要時だけ調整
- 勝ち点・得点・紫・違反の優先順と多い順／少ない順を、予選とトーナメントで別々に保存
- 勝ち点は1ゲーム（3マッチ）単位で勝利3点・引き分け各1点・敗北0点として集計
- 未実施で全数値が0のグループ編成では順位を非表示
- 旧式のAグループ全試合→Bグループ全試合という予選順も、対戦情報を保持してA1→B1→C1…へ移行
- トーナメント対戦・接続編集は通常時に折りたたみ、必要時だけ展開
- ログインは認証と大会データ取得を一連で完了し、一時的な通信失敗時は自動再試行
- グループごとの自動進出順位とトーナメント総進出数をグループ画面から設定
- グループ・タイムスケジュール・トーナメント間の互換項目は同一状態を使ってリアルタイム双方向同期
- ページを開くたびに管理者ログインを表示し、ログイン後だけ大会データを読み込み
- グループ数・各グループ人数を入力すると、反映ボタンなしでグループ枠と予選を即時更新
- ランダム組み分けは誤操作防止の1秒長押しで実行
- ランダム組み分けは管理者が専用ボタンを1秒長押しした場合だけ「予選リーグ_結果」へ反映可能。反映先が空欄のときだけ書き込み、既存値は上書きしない
- 「予選リーグ_結果」への反映前にセル・枠・チーム名を一覧確認し、反映時にも全グループ領域の空欄と見出しを再検証。失敗時は変更前のセル内容へ自動復元
- 大会編成・チームリストの確定保存も変更前内容をバックアップし、途中失敗時は自動復元
- 保存開始時にサーバー更新番号を比較し、別端末・メインアプリの新着結果がある場合は差分項目を表示して上書き／中止を選択
- 表示専用URLは大会単位で旧URLを無効化して再発行可能
- 表示専用URLは無期限または指定日までの有効期限を設定可能
- 管理版は外部埋め込みを禁止し、表示専用general版だけ埋め込みを許可
- QRコードは外部APIへURLを送らず、端末内で生成
- 未保存キャッシュは30日で自動失効し、管理画面から手動削除可能
- タイムスケジュールはドラッグ操作に加え「上へ／下へ」で並べ替え可能
- タイムスケジュールのドラッグ並べ替え、試合追加・削除、試合ID・区分・対戦・時刻の手動編集
- 新規大会のタイムスケジュール先頭に編集・削除可能な「調整時間 60分」を初期作成
- 試合区分・コート・チーム・結果は候補選択を基本に、任意の手入力にも対応
- タイムスケジュールとトーナメントのチーム候補に「Aグループ1位」などを自動追加し、順位確定後は該当チーム名へ解決
- 調整時間・休憩は対戦欄を非表示にし、開始時刻と終了時刻を表示（「10分」などから終了時刻を補完）
- 表示用タイムスケジュールは詳細設定から、全体文字サイズ・行間・列ごとの表示、文字サイズ、列幅を調整
- 編集操作ごとに管理者アカウント別の端末キャッシュへ即時保存し、通信断・再起動後も未確定変更を復元
- 初回利用者向けの操作ガイドと、最大50段階の「元に戻す」に対応
- トーナメント線は枠の実寸と接続順から直線・直角で自動描画し、ラウンド内の枠順と線のレーンを自動整理して重なり・交差を抑制
- 線編集モードでは勝者／敗者の接続点から次の試合へドラッグまたはクリックで直接接続し、線そのものまたは黄色ハンドルをマウス／タッチで動かして曲がり位置を個別調整
- シードは0〜32枠で、出場元・合流試合・チーム1／2側を個別に設定
- 管理者版から大会アカウント固定の署名付き表示専用URLとQRコードを発行
- 表示専用URLダイアログから大会名付きPNGとしてQR画像を保存し、コーチ・保護者・観覧者へ共有可能
- 表示専用general版はログイン・管理編集・スプレッドシート・保存機能を表示せず、グループ・スケジュール・トーナメント・リンクを公開
- general版のリンク画面は現在の大会専用URL・QRだけを表示し、メインアプリ2種類の共通公開URLは表示しない
- MASTER（rsam）はGAS管理に登録された全アカウントのgeneral版URL・QRを一括発行可能
- 表示専用版は3秒間隔で変更を確認し、2秒共有キャッシュと保存時の即時破棄で反映速度とGAS負荷を両立
- 表示専用版は3秒ごとに軽量な更新番号だけ確認し、変更時のみ大会データ全体を再取得
- 表示専用版はスマートフォン／タブレット向けに文字サイズ・余白・横スクロールを自動最適化
- 管理者版に公式サイト・予選会・ルール・公開URL QR・クレジットのリンク画面を用意
- 開いている画面だけを遅延描画し、内容が同じ自動更新では状態・DOMを再生成しない軽量表示
- トーナメント再描画時に不要になった線位置監視を解放し、表示専用APIでは編集用チーム列を読み込まない
- タイムスケジュールの「○○ 勝者／敗者」参照からトーナメント接続線を自動生成
- 16:9 / 16:10 の大会運営モニターに対応

管理者アカウントを追加する場合は「GAS管理」の列名を維持し、管理者パスワード、WebアプリURL、スプレッドシートURLを入力します。大会固有データは接続先の「大会編成」シートへ保存されます。

## PWA としてホーム画面に追加する方法

### Android Chrome

1. 公開 URL を Chrome で開く
2. メニューから「ホーム画面に追加」または「アプリをインストール」を選択
3. 追加後、ホーム画面のアイコンから起動

### iPhone / iPad Safari

1. 公開 URL を Safari で開く
2. 共有ボタンを押す
3. 「ホーム画面に追加」を選択
4. 追加後、ホーム画面のアイコンから起動

## オフライン時の挙動

一度オンラインで読み込んだ後は、キャッシュ済みの HTML、CSS、JavaScript、画像、フォント、manifest、Service Worker を使って起動できます。

オフライン時でも利用できるもの:

- 基本 UI
- タイマー
- 10カウント / 5カウント
- ボールランダマイザー
- 試合記録
- 端末内のローカル履歴確認

オフライン時に制限されるもの:

- GAS 送信
- スプレッドシート読み込み
- 外部リンク表示
- ニュースやルールの外部参照

通信が必要な処理に失敗した場合は、UI を崩さずエラーメッセージを表示します。

## 音声チェック

大会前に管理画面の詳細設定から音声チェックを行ってください。

- 端末音量を上げる
- マナーモード、消音スイッチ、ブラウザの音声許可を確認する
- 11秒タイマーで、画面表示と音のタイミングが合っているか確認する

## 注意事項

- 本アプリは大会運営、練習、記録を支援する補助ツールです。
- 正式な競技ルール、Q&A、運営判断は WRO 公式資料を確認してください。
- ネットワーク状況やブラウザ制限により、全画面表示、画面向き固定、QR 読み込み、外部送信が利用できない場合があります。
- GAS / スプレッドシート連携を使う場合は、利用者側で正しい Web アプリ URL と権限設定を行ってください。
